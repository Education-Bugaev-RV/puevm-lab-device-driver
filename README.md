# Лабораторная работа: «Реализация драйверов для устройств»

# Branch complete-solution

Ветка для реализации полного решения задач поставленных в работе.

## Описание
В данном репозитории представлены материалы для выполнения лабораторной работы, посвященной реализации драйверов для внешних устройств (в данной работе конкретно для компьютерной мыши PS/2)

[Файл с описанием лабораторной работы содержит:](./Лабораторная%20по%20драйверам.pdf)
- Введение в тему,
- Цель работы,
- Практическую часть,
- Контрольные вопросы,
- Перечень отчетных материалов.


Работа состоит из 7-ми последовательных частей. 
Для выполнения каждой части студентам предоставляется заготовка проекта

* [Часть 0](./Part_0/) : Проект в данной директории содержит исходники с реализацией модулей и настройкой прерываний, которые могут помочь при выполнении работы,
* [Часть 1](./Part_1/) : Опрос данных мыши через PS/2,
* [Часть 2](./Part_2/) : Инициализация и сброс мыши,
* [Часть 3](./Part_3/) : Обработка пакетов перемещения мыши,
* [Часть 4](./Part_4/) : Обработка прерываний от мыши,
* [Часть 5](./Part_5/) : Ограничение перемещений мыши в пределах экрана,
* [Часть 6](./Part_6/) : Отображение указателя мыши на VGA,
* Часть 7* : Анимация и интерактивная игра с мышью (не реализовано).
