# Часть 3. Обработка пакетов перемещения мыши
В этой части вы узнаете, как обрабатывать сообщения, отправляемые устройством мыши, чтобы указать изменение его положения и состояния кнопок. Изменение положения обозначается двумя 9-разрядными цифрами со знаком, одна из которых обозначает изменение горизонтального положения, а другая - вертикального. Перемещение мыши вправо приводит к положительному изменению положения мыши по горизонтали, а перемещение мыши влево обозначается отрицательным значением. Аналогично, когда вы перемещаете мышь вперед, изменение вертикального положения является положительным, а когда вы тянете ее на себя, оно является отрицательным. Состояние кнопок мыши определяется с помощью трех разрядов, по одному на кнопку в обычной трехкнопочной мыши. При нажатии кнопки соответствующий бит устанавливается равным 1, в противном случае бит устанавливается равным 0. 

По умолчанию мышь, которая включена, отправляет 3-байтовые пакеты через порт PS/2, чтобы сообщить о своем состоянии. Формат пакета приведен в ниже.

![Пакет данных компьютерной мыши PS/2 состоящий из 3-х байт](../media_docs/Пакет%20данных%20компьютерной%20мыши%20PS2%20состоящий%20из%203-х%20байт.png)

Бит 3 первого байта равен 1, что указывает на то, что два следующих за ним байта являются частью 3-байтового пакета данных. Кроме того, первый байт содержит состояние трех кнопок в битах со 2 по 0, а также биты знака и переполнения для перемещения по осям x и y. Оставшиеся два байта содержат 8-битные части движений мыши по осям x и y. 

Напишите программу на языке Си, которая инициализирует мышь и обрабатывает 3-байтовые пакеты перемещения, полученные от мыши. Ваша программа должна декодировать пакеты и отображать состояние кнопок на LEDR[2..0], изменение положения x на HEX[5..3] и изменение положения y на HEX[2..0].
