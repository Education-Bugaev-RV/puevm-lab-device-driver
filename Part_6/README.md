# Часть 6. Отображение указателя мыши на VGA

В этой части вы должны реализовать процедуры для отображения указателя мыши на экране. Для отображения указателя мыши на экране вы будете использовать процессоры VGA в компьютере серии DE. Эти ядра реализуют интерфейс VGA, который позволяет выводить изображение на экран компьютера с разрешением 320 на 240 пикселей. Изображение, отображаемое на экране, сохраняется в памяти и может быть легко изменено.

Чтобы определить форму указателя мыши, используйте матрицу из 16 строк и 8 столбцов. Каждая запись в матрице должна содержать одно из трех значений:

* 0 – указывает, что соответствующий пиксель указателя мыши черный.
* 1 – указывает, что соответствующий пиксель указателя мыши белый.
* -1 – указывает, что соответствующий пиксель указателя мыши прозрачный.

Адаптируйте ваш драйвер для перемещения указателя мыши по экрану. Определите две новые:

1. **draw_mouse**: сохраняет изображение под указателем мыши и рисует его в текущем местоположении. Используйте матрицу, описанную выше, для рисования указателя на экране, предполагая, что верхний левый угол изображения указателя находится в текущем местоположении мыши. Эта функция должна быть видна только драйверу.

2. **erase_mouse**: удаляет курсор с экрана, перерисовав изображение под ним. Эта функция должна быть видна только драйверу.

Измените процедуру обслуживания прерываний PS/2, чтобы при изменении положения мыши вызывались две вышеуказанные функции.

Запустите программу из части 5 и подключите VGA-выход платы DE-series к монитору компьютера. Вы должны иметь возможность видеть координаты указателя мыши на шестнадцатеричных дисплеях и сам указатель мыши на экране при перемещении мыши.
