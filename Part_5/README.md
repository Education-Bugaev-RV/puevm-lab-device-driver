# Часть 4. Обработка прерываний от мыши
В этой части вы будете обрабатывать сообщения мыши, используя процедуру обработки прерываний. Процедура обработки прерываний (ISR) - это функция, которая выполняется при возникновении прерывания. Прерывание произойдет, когда бит RE в управляющем регистре PS/2 будет установлен в значение 1 и на порт PS/2 поступит сообщение, готовое к считыванию.

Для этого измените свою программу на языке Си из части 3, реализовав четыре функции:

1.	***initialize_driver***	

разрешить драйверу обрабатывать сообщения с помощью мыши. Эта функция должна перезагрузить мышь и разрешить прерывания для порта PS/2 на компьютере серии DE. 

2.	***disable_driver***	

отключить обработку сообщений с помощью мыши. Кроме того, отключите прерывания для порта PS/2. 

3.	***get_mouse_change***	

получите информацию о последних изменениях положения и кнопок мыши, о которых сообщает мышь. 

4.	***PS2_ISR***	

программа обслуживания прерываний, которая обрабатывает события, связанные с мышью.
