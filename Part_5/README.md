# Часть 5. Ограничение перемещений мыши в пределах экрана

В этой части вы улучшите драйвер вашего устройства, чтобы отслеживать местоположение мыши и ограничивать ее перемещения указанными границами. Для этого вы определите пять переменных: две для отслеживания текущего горизонтального и вертикального положения мыши, одна для отслеживания состояния кнопок мыши и две для указания максимальных горизонтальных и вертикальных координат, в которых может находиться мышь.

Вам необходимо создать драйвер устройства для мыши, содержащий следующие функции:

1. ***initialize_driver*** – как в части 4.
2. ***disable_driver*** – как в части 4.
3. ***set_mouse_bounds***( maxx, maxy )
установите максимальные координаты x и y, которые может иметь мышь.
4. ***get_mouse_state***
считывает текущее положение мыши на экране и состояние трех ее кнопок.
5. ***get_mouse_change*** – как в части 4.
6. ***PS2_ISR*** – как в части IV.

Напишите программу, которая отображает положение мыши, используя левые четыре hex-индикатора для отображения положения x и четыре правых для отображения положения y.

Установите максимальные координаты мыши x и y равными 319 и 239 соответственно.
